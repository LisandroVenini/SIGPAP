# Objetivos del Sistema

| OBJ–01  | Digitalización e Integración Operativa  |
| :---- | :---- |
| **Descripción**  | Centralizar la información de producción, inventario y proveedores en una plataforma única, eliminando los silos de datos mediante una interfaz de "baja fricción" que facilite la captura ágil de los partes diarios en el piso de planta. |
| **Estabilidad**  | Alta |
| **Comentarios**  | Constituye la base transaccional del sistema, indispensable para recolectar la información cruda que alimentará al motor predictivo.  |

| OBJ–02  | Prevención Proactiva de Cuellos de Botella  |
| :---- | :---- |
| **Descripción**  | Proveer a la gerencia de alertas tempranas sobre posibles retrasos en las entregas, utilizando algoritmos de Machine Learning para recalcular predictivamente el cronograma en base a la desviación de la Tasa de Rendimiento Real de cada sector productivo. |
| **Estabilidad**  | Alta |
| **Comentarios**  | Representa el principal cambio de paradigma de la plataforma, pasando de una gestión reactiva a una proactiva.  |

| OBJ–03 | Sincronización Inteligente de Abastecimiento  |
| :---- | :---- |
| **Descripción**  | Automatizar la detección de inminentes quiebres de stock mediante el cruce del ritmo de consumo interno y los tiempos de entrega estadísticos de los proveedores, adelantando pedidos y gestionando licitaciones automáticas. |
| **Estabilidad**  | Alta |
| **Comentarios**  | Integra el Módulo de Inventario con el Módulo de Proveedores, garantizando la continuidad ininterrumpida de las operaciones en la fábrica.  |

| OBJ–04 | Soporte Gerencial mediante Simulación de Escenarios  |
| :---- | :---- |
| **Descripción**  | Facilitar un entorno de simulación seguro que permita a la dirección proyectar matemática y operativamente el impacto de insertar pedidos de alta urgencia en la cola de producción actual. |
| **Estabilidad**  | Alta  |
| **Comentarios**  | Aporta el respaldo analítico necesario para la toma de decisiones comerciales críticas sin alterar los datos operativos reales. |

| OBJ–05 | Gestión de Inventario mediante Reservas Lógicas  |
| :---- | :---- |
| **Descripción**  | Implementar un modelo de control de stock que diferencie dinámicamente el inventario físico real del inventario comprometido para las órdenes de producción en curso. |
| **Estabilidad**  | Alta |
| **Comentarios**  | Evita falsos positivos de disponibilidad de materiales, protegiendo la integridad de las órdenes que ya se encuentran en el flujo de fabricación.  |
